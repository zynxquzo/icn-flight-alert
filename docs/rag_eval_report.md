# RAG 도입 전/후 응답 정확도 평가

## 배경

챗봇이 LLM(gpt-4o-mini) 단독으로 인천공항 시설 위치를 답변할 때, 학습 데이터에 없는
공항 특수 정보(시설의 정확한 층수·구역)에 대해 그럴듯하지만 틀린 답을 자신 있게 제시하는
현상(환각)이 있었다. 이를 확인하고 RAG 도입 효과를 수치로 검증하기 위해 평가 스크립트를
작성해 실행했다.

## 방법론

- 스크립트: [`scripts/eval_rag_grounding.py`](../scripts/eval_rag_grounding.py)
- 원본 응답 전체 기록: [`scripts/eval_rag_grounding_results.json`](../scripts/eval_rag_grounding_results.json)
- 평가셋: 인천공항 공식 사이트(airport.kr)를 크롤링해 Chroma에 인덱싱한 문서
  (`source_type=official_website`, 총 200건) 중 **이름이 유일해 정답이 모호하지 않은
  시설 18곳**을 선정. 각 시설의 정확한 층수·위치를 크롤링 원문에서 그대로 가져와
  정답(ground truth)으로 사용했다. seed 음식점 데이터(36건, 크롤링 출처 아님)는
  평가셋에서 제외했다.
- 각 질문마다 동일한 `ChatbotService.chat()`을 두 모드로 호출:
  - **legacy**: `RAG_ENABLED=false` — gpt-4o-mini 단독 응답
  - **rag**: `RAG_ENABLED=true`, `RAG_AGENT_ENABLED=false` — Chroma 하이브리드 검색으로
    가져온 공식 문서를 컨텍스트로 넣어 응답 (에이전트 도구 호출은 배제해 RAG 유무만 비교)
- 채점은 LLM judge 없이 **정규식 기반으로 결정론적으로** 수행:
  1. 정답 키워드(예: "지하1층", "9번 출입구") 포함 여부 → keyword hit rate
  2. 응답이 언급한 층수(`\d+층` / `지하\d+층` 패턴 추출)가 실제 층수와 일치하는지 →
     층수 정오 판정("환각" 여부의 핵심 지표)

## 결과

| 지표 | Legacy (LLM 단독) | RAG |
|---|---|---|
| 질문 수 | 18 | 18 |
| 평균 키워드 일치율 | **20.4%** | **95.4%** |
| 정답 키워드 완전 일치 | 0/18 (0%) | 16/18 (88.9%) |
| 층수를 명시적으로 답변 | 18/18 (100%) | 18/18 (100%) |
| **층수 정답** | **6/18 (33.3%)** | **18/18 (100%)** |
| **층수 오답(환각)** | **12/18 (66.7%)** | **0/18 (0%)** |

**핵심 수치: LLM 단독 응답은 18개 질문 중 12개(66.7%)에서 실제와 다른 층수를 확신에 찬
어조로 제시했다. RAG 도입 후 동일 질문 18개 전부(100%) 정확한 층수로 응답했다.**

## 구체적 사례 (환각 → 정정)

| 시설 | 실제 위치 | Legacy 답변 | RAG 답변 |
|---|---|---|---|
| 인하대학교병원 공항의료센터 | 지하1층 동편 | "1층에 위치" | "지하 1층 동편" |
| 캡슐호텔 다락휴 | 교통센터 1층 중앙 | "4층에 위치" | "1층 중앙" |
| 환승호텔 | 4층 면세지역 11번 게이트 | "3층에 위치" | "4층 면세지역 11번 게이트 부근" |
| 여권민원센터 | 3층 G 체크인카운터 부근 | "1층에 위치" | "3층 일반지역 G 체크인카운터 부근" |
| 우편취급국 | 2층 중앙 | "1층에 위치" | "2층에 위치" |
| 세탁소(크린업에어) | 지하1층 서편 | "1층에 위치" | "지하 1층 서편" |

전체 18개 질문의 원문 응답은 `scripts/eval_rag_grounding_results.json`에서 확인할 수 있다.

## 한계

- 표본 18개는 소규모이며 T1 시설 위치 질의로 한정했다(운영시간·요금 등 다른 항목은 미평가).
- "층수 정오"라는 단일 축으로 환각을 정의했다 — 문장 전체의 사실성을 LLM judge로
  교차 검증하지는 않았다.
- gpt-4o-mini 특정 스냅샷 기준이며, 모델이 바뀌면 결과가 달라질 수 있다.
